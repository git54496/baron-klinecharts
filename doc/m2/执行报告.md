## 2. 实现契约

### 2.1 Scene 与版本

- `sceneVersion` 继续为 `1`；Runtime version 允许 `0.1.0`、`0.2.0`。
- `0.1.0` Scene 必须省略轴 `scale`；`0.2.0` Scene 的轴必须显式给出 `linear` 或 `logarithmic`。
- 仅 candle 主价格轴允许 `logarithmic`；对数模式拒绝非有限数和所有非正 OHLC/价格坐标。
- 新增 `priceMeasurement`，只持久化 start/end 数据锚点与通用 styles/metadata；涨跌额与涨跌幅均由 Adapter 派生，不写回 Scene。
- Overlay 颜色继续只接受 canonical `rgba(r, g, b, a)`。HTML `<input type=color>` 的 `#RRGGBB` 在 Web toolbar 边界精确转换为 `rgba(r, g, b, 1)`；没有扩展 Scene 接受 hex，M1 canonical/hash 因此不变。

### 2.2 Adapter 与交互

- linear/logarithmic 映射到 KLineCharts 的 `normal/logarithm`，轴切换先验证、再提交引擎、最后原子提交 Scene；失败恢复原引擎轴且不改变最后可导出 Scene。
- 量度显示按 start price 为分母派生；AAPL 300→330 输出 `+30.000 (+10.00%)`。
- 整体移动保持绝对价差与相同 bar-index 差；锚点移动只更新目标锚点。
- 命中半径冻结为主体 12 CSS px、锚点 14 CSS px，边界包含；优先级为锚点高于主体，其后按 zLevel、Scene 顺序、anchor index 确定。
- locked overlay 可选择但不可拖动，invisible overlay 不参与命中。
- controlled horizontal line 与 priceMeasurement 由 Adapter 提供确定性交互；其他 KLineCharts overlay 仍由引擎所有，不截断其原生交互。

### 2.3 Runtime、事件与工具栏

- 实现根契约 10.4 的统一事件 envelope、成功/取消/样式顺序、五类取消 reason、direct/request 删除和 opaque host action。
- 新增公开能力：`setPriceScale`、`projectPoint`、`hitTestOverlay`、`updateOverlayStyles`、`requestOverlayDelete`、`requestHostAction`。
- progress 不修改 committed Scene；Escape、pointer cancel、window blur、destroy、validation error 均恢复最后提交状态并发出相应取消序列。
- 标准工具栏新增量度、轴模式、线型、线宽、canonical 颜色、direct/request 删除和 opaque host action；不含 confirmation、price version、structure/replay 等宿主业务语义。
