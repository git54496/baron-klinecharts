# baron-klinecharts M2 量度与精确交互实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task. Steps use checkbox (`- [ ]`) tracking. 本仓规则禁止子智能体、worktree 及未经授权的 Git/发布操作；每个授权停点必须停止并回传总 session。

**Goal:** 发布一组正式 npm/Python 版本，使消费者能够在稳定 Scene 上使用线性/对数坐标、量度涨幅、水平线精确编辑和完整过程事件，并可靠导出恢复。

**Architecture:** Scene Schema 定义稳定数据表达，Adapter 负责 KLineCharts 映射，Web Runtime 提供交互与宿主事件，Python 包同步验证相同 Scene。所有业务语义留在宿主 `my-cage`，图表仓只输出通用能力。

**Tech Stack:** TypeScript、JSON Schema、KLineCharts、React/Vue/Vanilla consumers、Vitest、Playwright、Python、npm workspaces。

**目标文档:** `目标说明.md`

**跨仓文档:** `../../../doc/m2/总目标与决策基线.md`、`../../../doc/m2/跨仓实施编排.md`、`../../../doc/m2/跨仓验收卡.md`、`../../../doc/m2/腾讯云统一验证方案.md`
