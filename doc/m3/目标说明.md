# baron-klinecharts M3 目标说明

> 上位文档：`../../../doc/m3/总目标与决策基线.md`、`../../../doc/m3/跨仓实施编排.md`

## 1. 目标

为 M3 每日决策工作台补齐正式图表能力：

- MA18/45/60/200/250 独立开关；
- VOL 副图与 MAVOL5/10/20；
- 蜡烛/折线切换、全屏和十字线 OHLCV 信息；
- 本轮正式绘图交互矩阵；
- 发布新的 npm/Python 正式版本并保持 Scene/Runtime 契约兼容演进。

## 2. 边界

- 不理解方向、池子、共振或评估业务语义；
- 不引入第二图表引擎；
- 指标与绘图能力以正式发布制品交付，不通过源码路径供下游消费。

## 3. 交付物

- 指标、全屏、十字线与绘图矩阵的 Scene/Overlay/Runtime/事件契约；
- 跨语言与浏览器回归测试；
- npm/PyPI/GitHub Release 正式发布；
- 干净消费者验证证据。
