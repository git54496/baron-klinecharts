# 同标的跨周期画线（编排层）

## 1. 文档定位

本文件为《全图表统一画图能力技术方案》的跨周期编排补充说明。它只负责业务编排，不承接画线几何、Schema、Canonical、Runtime 事务或引擎边界定义。

## 2. 与上位规范的关系

跨周期方案必须且仅必须复用：

- `DrawingDocument`：画线事实权威
- `DrawableWorkspaceDocument`：工作区组合与导出权威
- `DrawingProjectionService`：时间与价格坐标的跨场景投影权威
- `DrawableWorkspaceRuntime`：候选/确认画线会话权威

跨周期方案不得重复定义上述概念的接口、Schema、Canonical、事件协议、投影算法或 runtime 行为。

## 3. 业务职责范围（允许）

- 业务标的与 `scopeKey` 的绑定与校验
- 周期 Scene 的装配与切换编排
- 与行情源（含 `fxxking-data`）的数据装配协作
- 宿主侧持久化幂等与审计编排（持久化副作用不写入通用契约）

## 4. 业务职责范围（禁止）

- 不能定义或扩展画线类型、样式、几何
- 不能定义画线 Canonical、Drawing/Workspace Runtime 错误码或运行时事件协议
- 不能实现/复制投影算法
- 不能处理工作区导入导出渲染入口的核心协议
- 不能在跨周期层里要求引擎行为变更替代能力缺口

## 5. 跨周期流程（统一运行时下）

1. 宿主按业务 `scopeKey` 读取同标的 `DrawableWorkspaceDocument`
2. 以 `host-confirmed` 创建 `DrawableWorkspaceRuntime`，再连接只做业务编排的
   `CrossPeriodDrawingCoordinator`
3. 协调器校验宿主显式提供的 `instrumentKey → scopeKey` 绑定；不得从 ticker/name 推断
4. 宿主 Scene loader 注入候选周期场景（Chart 或 TimeSeries），周期切换仅替换 scene
   分支，不改 `DrawingDocument`
5. 画线交互产出候选后由协调器调用宿主持久化端口，回执 canonical hash 精确相等后
   才调用公共 Runtime commit，否则 reject 恢复 confirmed
6. 所有失败按统一运行时回滚规则处理，恢复上次确认状态

`CrossPeriodDrawingCoordinator` 不是新的画线 Runtime：它不提供几何、投影、Adapter、
Chart 或 Workspace 事务实现，只消费 `DrawableWorkspaceRuntime` 的公开
`replaceScene/commit/reject/subscribe` 能力。详细执行与验证门见
《同标的跨周期画线实施计划》。

协调器可以为 pending UI、Scene loader 和宿主持久化失败提供业务编排状态与错误分类；
这些信息不进入 Drawing/Workspace 契约，也不扩展 Workspace Runtime 事件协议。

## 6. Legacy 与 Workspace 隔离

- `ChartScene.overlays` 仍保留为 Legacy 模式显示字段，不承担工作区画线持久化
- 工作区导出仅输出 `DrawableWorkspaceDocument`
- 任何场景下不得把 Legacy 导出与工作区导出互相转换

## 7. 跨周期验收门

- 编排层文本不得出现独立画线几何/投影/Workspace 运行时权威定义
- 画线语义一致性以统一方案验收结果为准，不在本文件复用判定
- 出现能力缺口，应先在统一方案补齐后再扩展业务编排
