# baron-klinecharts M4 目标说明

> 上位文档：`../../../doc/m4/总目标与决策基线.md`、`../../../doc/m4/跨仓实施编排.md`

## 1. 目标

- 固定满足当期要求的正式版本（当前 `0.5.1`）；
- 回归全屏、Scene 恢复和通知链接打开后的图表状态；
- 只有出现真实公共能力缺口时才发布新版本。

## 2. 边界

- 不实现业务调度、日报或飞书语义；
- 无缺口时不发布新版本。

## 3. 交付物

- M4 回归证据（全屏、Scene 恢复、通知链接打开后的图表状态）；
- 若存在缺口：修复提交、正式版本与干净消费者验证证据。
