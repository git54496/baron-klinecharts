# 通用时间序列实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变任何现有 ChartScene Client API 的前提下，为 `baron-klinecharts 0.3.0` 增加可发布的 `TimeSeriesScene v1`、Browser Runtime、无头渲染和 Python API。

**Architecture:** 新 Scene 使用独立 Schema、类型、错误和校验入口；Adapter 用隐藏的零值 OHLC 承载时间轴，每条业务线映射为受控 Indicator；Web 与 Render Runtime 只通过新入口消费它。旧 `ChartScene` 路径不分支、不迁移、不增加封闭错误联合成员，回归门禁保证旧 API 和视觉结果不变。

**Tech Stack:** TypeScript 5.9.3、JSON Schema 2020-12、AJV standalone、KLineCharts 10.0.0、Vitest、Playwright、Vite、Python 3.11+、PyPI/npm release tooling。

**Spec:** `doc/time-series/通用时间序列设计.md`

**Git constraint:** 本计划不包含 `git add`、`commit`、`push` 或发布动作；本地发布候选验证完成后必须单独取得用户授权。

```ts
interface TimeSeriesCarrierData extends MarketData {
  readonly __baronTimeSeriesValues: Readonly<Record<string, number | null>>;
}

  timestamp,
  open: 0,
  high: 0,
  low: 0,
  close: 0,
  volume: 0,

```

  私有字段不得进入公开类型、数值轴或导出结果。
