03 / 识别规则

不用文字，也能区分三种线

A

线段

两个实心端点，线只存在于端点之间。

B

射线

一个起点、一个方向点，线向边界继续延伸。

C

无限直线

两个方向点，线在两侧都贯穿图标边界。
