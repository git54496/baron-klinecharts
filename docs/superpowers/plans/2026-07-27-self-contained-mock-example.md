# Self-Contained Mock Example Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This repository executes the plan inline with `superpowers:executing-plans` because its `AGENTS.md` explicitly prohibits subagents and worktrees unless separately authorized.

**Goal:** Add a deterministic, self-contained KLineCharts validation page that uses committed static market data and verifies identical Web, CLI, Python, HTML, and PNG behavior without depending on `fxxking-data`.

**Architecture:** A fixed-seed Node generator creates one schema-valid `ChartScene` JSON file. The existing Vanilla example imports that file through `@baron1996/klinecharts-runtime`, while Node, Playwright, CLI, and Python tests validate determinism, browser interaction, canonical serialization, hashing, and offline rendering. Runtime, schema, CLI, and Python public behavior remain unchanged.

**Tech Stack:** Node.js 22 ESM, TypeScript 5.9, Vite 7, Playwright 1.61, KLineCharts 10, Baron Scene Schema/Runtime/CLI, Python 3 unittest tooling.
