# 10.x 固定缩放档位与等间隙

## 范围

KLineCharts 固定为 10.0.0，Adapter / Web Runtime 本地构建版本 0.9.34。
开发工作树为 `baron-klinecharts-discrete-zoom`，分支 `codex/discrete-candle-zoom`，
基于 a7f726e 并承接前一轮 0.9.33 未提交的实体宽度修复；原目录改动保持不动。
交付本地 npm-pack 产物供 Cage 接入，尚未发布 npm。
2026-09-26 两仓合入并推送 main 后，Cage 通过 Git 部署到腾讯云上海完成线上验证。

适用于普通 ChartScene 和带缺口的 Scene v2 主蜡烛；TimeSeries 独立引擎不变。
不改变行情值、历史/实时数据生命周期和 Scene / Drawing 协议。

## 两个不同的问题

1. 原 10.0.0 的窄档位（例如 barSpace=3.6）会给出最终宽度 3；相邻取整后的中心
   可能只差 3px，导致实体接触。偶数宽度还可能被额外加 1px。
   2026-08-06 与 08-07 的同色、同开盘价实体会因此看起来合在一起。
2. 0.9.33 只用 9.x 的最终宽度规则修正实体。小数中心步长仍被每根分别取整，
   因而 AB、BC 的留白仍可能不同；实体也随取整出现宽度平台期。

0.9.34 取代宽度补丁：档位同时决定实体 W、留白 G、步长 P=W+G，不再沿用
连续缩放、独立横坐标取整、偶数实体扩宽和 0.82 比例公式。

## 固定序列

唯一规则表在 `packages/klinecharts-adapter/src/candle-zoom-levels.ts`。
每项为 `[实体宽度, 留白]`，从最密到最宽：

```text
[1,1], [2,1], [3,1], [4,2], [5,2], [6,2], [7,3], [8,3],
[9,4], [10,4], [11,4], [12,4], [13,5], [14,5], [15,6],
[16,6], [18,7], [20,8], [22,9], [24,10], [27,11], [30,12],
[33,13], [36,14]
```

这是产品明确选择的 24 档序列，不是声称复刻了富途的私有实现。
缩小时实体逐档变窄，间隙分阶段变小。基准步长范围 2–50 CSS px。
达到最密档后停止，不通过取消间隙继续缩小，也不静默抽样或聚合行情。

## 像素与横向位置

表中单位是 DPR=1 时的 CSS px。每档先统一换成物理像素：

```text
bodyPixels = max(1, round(W * DPR))
gapPixels  = max(1, round(G * DPR))
pitchPixels = bodyPixels + gapPixels
```

因此非整数 DPR 下，公开的 CSS barSpace 可能是小数，但物理像素步长是整数。
这与原来的任意小数步长不同。同一档内不会对每根的宽度/位置分别凑整。

只对共同实体左边界起点对齐一次，然后按整数 pitchPixels 排列。原点取末根 K，
每根使用相对末根的索引；向前补入历史时，末根原点和既有 K 的相对索引都不变。
不能用随数据长度增长的 index=0 原点重复取整，否则半像素边界附近会产生
历史补页后的 1px 偏移。此边界已纳入单元测试和原有历史补页像素测试。

实体宽度包含内描边，实心/空心/混合样式共享相同外边界。影线、实体、成交量、
指标、十字线及 Drawing 使用同一时间坐标中心。Drawing 的小数索引仍保持连续。
Scene v2 的真实缺口保留时间槽：隔着缺口的两根真实 K 本来就应有更大距离，
“等间隙”指相邻且有实体的连续槽，不是挤掉合法缺口。

浏览器缩放或跨屏改变 DPR 时，resize/resolution 监听按同一逻辑档重新对齐；
销毁 Chart 时解除监听，不修改全局原型或已安装的 node_modules。

## 缩放与兼容行为

- 滚轮、时间轴缩放手势：每次非零引擎缩放输入向对应方向切换一档。
- 双指捏合：两指欧氏间距累计净变化每 20 CSS px 切换一档，与初始间距和 DPR 无关。
  余量保留，反向移动抵消余量；一次事件跨越多个阈值时切换对应档数。
  新手势重置累计量，禁用缩放时仍消费距离，避免重新启用后补跳。
  引擎继续负责捏合命中、锚点与触摸仲裁；兼容钩子只作用于当前 Chart 实例。
- `setBarSpace` 和旧 Scene 视口：就近映射档位，正好居中选较密档，越界钳制。
  NaN、Infinity、零或负值不修改状态。
- `zoomAtCoordinate/DataIndex/Timestamp`：按原倍率求目标后吸附到档位；非 1 倍
  请求至少移动一档。保持引擎的 cursor/last_bar 锚点和 onZoom 实际倍率事件。
- 显式缩放的 animationDuration 不插值，直接到目标档；避免每动画帧跳一档导致过冲。
- 平移只改变共同起点，保持当前档位和 Y 轴比例。禁用缩放/平移仍有效。
- 每根共享像素对齐相位；缩放切换宽度奇偶时，锚点允许最多一个物理像素的对齐误差。

10.0.0 未公开这套布局策略的扩展接口，适配器使用受版本与结构断言保护的实例级
Store/蜡烛 Figure 桥接。未来升级引擎必须复查坐标反算、描边、生命周期与手势入口。
