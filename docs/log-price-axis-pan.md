# 对数价格轴平移刻度修复

## 问题与行为

2026-09-06 对比老虎国际 Pro 与 Cage 的 BE 前复权日 K：两端 K 线下移 60px，
Cage 原来的价格刻度从每档 50 改成每档 60，网格整体重新排列。
此前的平移修复已经保持 K 线的对数跨度，但引擎仍按可见价格差选取刻度。

现在主图对数价格轴通过正式 `createTicks` 回调生成刻度：

- 按对数跨度、图表高度和字体大小选择间距，使用固定的 `log10(price)=0` 基准。
- 平移时保持相邻刻度的价格倍数；旧刻度随 K 线移动，新刻度从边缘进入。
- 缩放或调整图表高度后按新密度选取间距；反向轴使用相同价格序列。
- 普通价格保留两位小数，极低价格或很密的刻度增加有效显示精度以避免重名。
- 沿用宿主的千位分隔符和小数折叠配置；线性轴继续使用引擎默认刻度。

修改仅位于适配器，不改变 Scene、行情、Drawing 数值或之前的平移比例算法。

## 验证

- 全部 npm 工作区构建通过。
- 适配器单元测试 97 项通过，覆盖低于 1 的价格、跨 1 范围、反向轴、
  连续平移、缩放密度、浮点阈值、字号与数字格式。
- `pan-scale.browser.spec.ts` 覆盖线性／对数、自动／手动范围、正向／反向轴，
  并对 60..480 价格范围连续平移 60、60、-120px，验证刻度与价格像素坐标对齐。
- Runtime 四项回归通过，覆盖线性／对数切换与重建、非正价格拒绝、工具栏。
- Chrome 本机模拟行情实测：133.35 刻度从 y=222 到 y=282，132.59 从 y=272
  到 y=332；K 线高点 132.76 同样下移 60px，刻度数值与间距保持稳定。
