# 带周期的文字标注

自由文字（`text`）在创建时记录周期，如 `2H`、`1D`、`1W`、`1M`。周期与内容分开保存，drawing 工具栏可独立修改周期、文字和背景色。切换图表周期不会重写文字标注的周期。

文字范围以起点时间／价格和对角终点时间／价格保存。初始点击自动根据文字长度生成范围；整体拖动保持时间跨度和价格轴空间内的高度，拖动四角可修改范围。绘制和命中均使用连续时间桶索引，因而 8 小时在 2 小时图中占 4 根 K 的宽度，在日线图中占约三分之一根 K 的宽度。对数、反向价格轴的像素转换使用引擎正式接口。

背景仍填满投影后的矩形范围；文字保持自然字形比例，按可用宽度和高度中较小的倍率等比例缩放，左上对齐。宽高变化不同步时允许背景内留白，不通过横向或纵向拉伸强行铺满。

投影宽度不足初始宽度的 28%（至少 44px），或高度不足 14px 时，显示直径 32px 的周期圆圈。选中圆圈显示完整内容和对象工具栏；空白处取消选择。折叠、展开和选中状态不写回 DrawingDocument。范围足够大时恢复完整文字。

兼容既有文档，不改变 schema。`metadata.baronTextPeriod` 保存 `{type, span}`；`metadata.baronTextBox` 保存 `{end: {timestamp, value}, width, height}`；原 `geometry.point` 和 `geometry.text` 保持权威。`width`／`height` 是首次布局尺寸，供最小显示阈值使用。旧文字仍按原来的固定字号显示，周期控件显示“未标记”；用户明确指定周期时才生成并保存范围，不在载入或周期切换时批量修改旧数据。

新增可选 `updateDrawingMetadata` 能力，沿用候选确认、锁定、只读、撤回和失败回滚机制。自定义 Figure 只在引擎初始化时注册，纯数据模块仍可在 Node 中加载。

验证覆盖：8 小时跨周期投影、四角拖动、保留跨度的整体移动、对数轴价格移动、创建周期、周期编辑、圆圈触摸选择、空白取消、重新载入及 1180／795／390px 工具栏布局。
